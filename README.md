# MeuSaldo — Dashboard Financeiro

Projeto acadêmico desenvolvido com HTML5, CSS3 e JavaScript ES6, sem frameworks.

## Como executar
1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador atualizado.
3. Cadastre receitas e despesas pelo formulário.

## Funcionalidades
- Resumo de entradas, saídas e saldo atualizado automaticamente.
- Cadastro de transações com validação dos campos.
- Exclusão individual e opção de limpar o histórico.
- Persistência dos dados usando `localStorage`.
- Layout responsivo com CSS Grid, Flexbox e media queries.

## Publicar no GitHub
1. Crie um repositório chamado `dashboard-financeiro`.
2. Envie `index.html`, `style.css`, `script.js` e `README.md`.
3. Para disponibilizar o site, acesse **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`.
4. Salve e aguarde o GitHub Pages publicar. Copie o link gerado para a entrega.

## Observação
Os dados ficam salvos apenas no navegador/dispositivo em que foram cadastrados. Não há login nem sincronização entre dispositivos.
